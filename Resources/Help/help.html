BoxMouse 使用帮助

本地运行的鼠标手势自动化工具 · 所有配置都在本机，不上传任何数据

三分钟上手

1. 给两个权限

打开「系统设置 → 隐私与安全性」，勾选两项：

辅助功能读鼠标事件、发合成按键、操作窗口。没有它，鼠标手势一条都不触发。 输入监控只用触摸板手势时才需要。

勾完建议重启一次应用。授权是跟着签名走的，用固定证书打包的版本升级后不会掉。

2. 从菜单栏进来

BoxMouse 是一个菜单栏常驻的应用：关掉窗口它不退出，引擎要在后台继续监听。

  • 点菜单栏图标 → 浮窗里有总开关、状态、手势计数和一键回主窗口。
  • 也可以在「设置 → 通用」里关掉 Dock 图标，变成纯菜单栏形态。
  • 要真正退出：⌘Q 或菜单里的「退出」。

3. 画一条手势试试

  1. 「手势」页 → 右上角「添加」。
  2. 在轨迹框里按住右键画一笔（比如一个 ⌐）。
  3. 给它配一个动作：快捷键、打开应用、窗口操作、浏览器操作都行。
  4. 保存后回到任意窗口，按住右键画同样的形状。

画歪了或者没触发，去「手势测试」页：手动画一笔就能看到与每条手势的相似度，不用到系统里试错。

鼠标手势

  • 触发键：默认按住右键画轨迹；也可以设置成中键、左键+修饰键等。
  • 修饰键：同一条轨迹配上 ⌥ ⌘ ⌃ ⇧ fn 就是另一条手势，互不冲突。
  • 作用域：每条手势可以只对某个应用、某个应用组生效，或者全局生效。按前台应用或指针所在应用判定。
  • 轨迹识别：对缩放、平移、方向敏感，但短轴有死区——竖线不会被掰弯，斜线不会被压平。

鼠标控制（滚轮 / 附加按键）

「鼠标」页，和手势引擎平级、互不隶属：你可能只想用平滑滚轮，一条手势都不想要。

平滑滚动

把鼠标滚轮的一格摊成逐帧的亚像素滚动，带缓动收尾。三个参数：

参数范围怎么调
滚动距离0.5 – 2.0×觉得"一格滚太近"就往上加
缓动时长100 – 500ms越长越"滑"，太长会发飘
速度增益1.0 – 3.0×连续滚动时越滚越快；单格不加速

加速键

按住选定的修饰键（默认提供 ⌥ ⌘ ⌃ ⇧ fn）再滚动，距离直接 ×2，适合长页面。触控板同样生效。

滚轮反方向

只影响鼠标滚轮。触控板 / 妙控鼠标的方向归系统「自然滚动」管，这里不碰——否则一开这个开关，触控板整个方向就反了。

附加按键

鼠标侧键（Forward / Back）各配一个动作，按下即执行。没配动作的侧键保持原样，仍然可以按住它画轨迹——不需要额外选什么"模式"。

触摸板手势

  • 支持三指上/下/左/右滑、两指捏合/张开、单指轻点。
  • 起手 200ms 内有宽限：手指是分先后落板的，第一帧常常只报一根，不会因为"手指数变了"就作废。
  • 单指在板上只算移动指针，不会被误判成滑动。

常见问题

手势完全没反应

  1. 看菜单栏图标的状态：是「正在监听」还是「引擎已关闭」。
  2. 「权限」页确认「辅助功能」是开的；改过权限要重启应用。
  3. 确认画的是手势的触发键，并且当前应用在它的作用域里。
  4. 去「手势测试」页手动画一笔，看相似度——能识别就是触发条件的问题。

触控板方向反了

去「系统设置 → 触控板 → 自然滚动」检查，这是系统级的。BoxMouse 的反方向开关不会改触控板。

滚轮滚起来不顺手

先把「缓动时长」调到 200~300ms、「速度增益」给 1.0~1.5，再从「滚动距离」微调。参数改动立刻生效，不用重启。

升级后权限又失效了

正常不会。授权绑定的是代码签名，用固定证书打包的版本升级后会保留；如果你是从别处下载的、用 ad-hoc 签名的包，每次升级 cdhash 都会变，就得重新勾一次。装的时候要用 ditto 复制，不要重新签名。

配置存在哪

设置~/Library/Application Support/BoxMouse/settings.json 手势~/Library/Application Support/BoxMouse/gestures.json 诊断日志~/Library/Application Support/BoxMouse/trackpad-trace.log

改这两个 json 之前先把应用退掉，否则它退出时会把内存里的值写回去，覆盖你的修改。想整体迁移就整个文件夹打包带走。

想看看它到底在干什么

「手势」页旁边的诊断面板会实时写日志到 trackpad-trace.log：每一轮触摸板手势的结论、作废原因（带具体数字，例如「作废：手指数 2→3（180ms，超出起手宽限）」）、以及滚轮每轮的输入和派发。

数据与隐私

  • 没有任何第三方依赖。
